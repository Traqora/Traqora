# Schema Contract Tests

Contract tests for Zod validation schemas used in the Traqora backend API.

## Test Files

- auth.schemas.contract.test.ts - Authentication schemas
- booking.schemas.contract.test.ts - Booking schemas
- refund.schemas.contract.test.ts - Refund schemas
- security.schemas.contract.test.ts - Security schemas
- flights.schemas.contract.test.ts - Flight search schema
- loyalty.schemas.contract.test.ts - Loyalty schemas
- subscriptions.schemas.contract.test.ts - Subscription schemas

## Running Tests

```bash
npm run test:schemas
```
