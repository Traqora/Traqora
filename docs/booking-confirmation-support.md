# Booking Confirmation Support Steps (V1)

## Overview
This guide provides support staff with safe lookup and escalation procedures for pending or inconsistent bookings.

## Safe Lookup Procedure
1. Verify the user identity using standard support authentication protocols.
2. Locate the booking reference in the primary database using the order ID or payment reference.
3. Check payment status through the integrated payment gateway dashboard before making any manual adjustments.

## Escalation Steps for Pending or Inconsistent Bookings
- **Pending Bookings**: If a booking remains in a pending state for more than 30 minutes despite successful payment, escalate to the Tier 2 Engineering team with the transaction ID.
- **Inconsistent Bookings**: If booking details do not match inventory records, temporarily flag the record as under review and notify the Operations lead immediately.
