# V1 Booking Contract Deployment Prerequisites

This document outlines the required accounts, assets, configuration, migration, and verification steps for deploying the v1 booking contract.

## 1. Required Accounts & Assets
- Deployer account funded with sufficient native XLM for deployment and base reserves.
- Asset issuer and distribution accounts configured for issued tokens (if applicable).

## 2. Configuration
- Set network passphrase (PUBLIC or TESTNET).
- Configure admin signer keys and threshold weights.

## 3. Migration & Verification
- Run contract compilation and verification tasks.
- Verify deployed WASM hash matches release artifacts.
